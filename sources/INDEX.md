# Index des sources

## Organisation

Les dossiers rangent chaque source selon **sa nature** : le genre de document et ce qu'il permet d'affirmer. Chaque source est dans un seul dossier. Les **thèmes** sont suivis dans le tableau ci-dessous, et une source peut en couvrir plusieurs. Le classement doit rester intuitif : en cas de doute, choisir le dossier où l'on irait chercher la source, et ajuster les dossiers si une nouvelle catégorie apparaît.

| Dossier | Contenu | Ce que ça permet d'affirmer |
|---|---|---|
| `1 - Revues systematiques` | Revues systématiques, méta-analyses, revues Cochrane, revues narratives systématiques, revues de portée | Synthèse de plusieurs études |
| `2 - Etudes cliniques` | Études menées **sur des patients** : essais randomisés, essais croisés, cohortes, études qualitatives, études pilotes | Une étude, des données originales sur des patients |
| `3 - Theses et modeles cliniques` | Thèses, modèles conceptuels, propositions de protocole, avis d'experts | Raisonnement clinique, peu ou pas validé |
| `4 - Documents institutionnels` | HAS, INRS, sociétés savantes, recommandations officielles | Avis institutionnel ou consensus |
| `5 - Etudes techniques et jeux de donnees` | Capteurs, reconnaissance de gestes, algorithmes, jeux de données, en général sur des **sujets sains** | Faisabilité technique, pas de preuve clinique |

**Nommage :** `Auteur Année - Titre court.pdf`. Pour deux auteurs, on écrit `Auteur1 Auteur2`. À partir de trois, on écrit seulement le premier auteur. L'année est celle de publication.
