# Index des sources

## Organisation

Les dossiers classent chaque source selon **son type de preuve**, qui est unique. Les **thèmes** sont suivis dans le tableau ci-dessous, et une source peut en couvrir plusieurs.

| Dossier | Contenu | Exemples de niveau de preuve |
|---|---|---|
| `1 - Revues systematiques` | Revues systématiques, méta-analyses, revues Cochrane, revues narratives systématiques | Synthèse de plusieurs études |
| `2 - Etudes primaires` | Essais randomisés, essais croisés, cohortes, études qualitatives, études de cas publiées seules | Une étude, des données originales |
| `3 - Theses et modeles cliniques` | Thèses, modèles conceptuels, propositions de protocole, avis d'experts | Raisonnement clinique, peu ou pas validé |
| `4 - Documents institutionnels` | HAS, INRS, sociétés savantes, recommandations officielles | Avis institutionnel ou consensus |

**Nommage :** `Auteur Année - Titre court.pdf`. Pour deux auteurs, on écrit `Auteur1 Auteur2`. À partir de trois, on écrit seulement le premier auteur. L'année est celle de publication.
