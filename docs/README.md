## En une phrase

On collecte et on analyse la littérature pour savoir si une rééducation de la main **gamifiée**, fondée sur des **activités familières appréciées** (cuisine…), améliore **l'observance** et **la récupération** tout en **respectant le protocole** prescrit. Il n'y a pas encore de développement logiciel dans ce dépôt.
